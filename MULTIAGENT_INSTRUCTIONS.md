# Инструкции по работе мультиагентной системы генерации резюме

## Общие принципы работы

Мультиагентная система генерации резюме состоит из нескольких специализированных агентов, каждый из которых выполняет свою роль в процессе создания качественного резюме:

- **Generator Agent** - генерирует резюме в структурированном формате
- **Checker Agent** - проверяет качество данных профиля
- **Search Agent** - собирает информацию о требованиях работодателей
- **Template Selector Agent** - выбирает подходящий формат резюме

## Структурированный вывод (Structured Output)

Все агенты системы используют строго определённые JSON-схемы для генерации выходных данных. Это обеспечивает:

- Единообразие формата данных
- Легкость интеграции между агентами
- Надежную валидацию данных
- Совместимость с различными форматами резюме

### Требования к структурированному выводу:

1. **Соответствие схеме**: Все генерируемые данные должны строго соответствовать JSON-схеме выбранного шаблона
2. **Типизация**: Все поля должны соответствовать определённым в схеме типам данных
3. **Обязательные поля**: Все обязательные поля должны быть заполнены или явно помечены как отсутствующие
4. **Форматирование**: Данные должны соответствовать ожидаемым форматам (даты, email, телефоны и т.д.)

## Обработка отсутствующих данных

Одним из ключевых принципов системы является **честность в данных**. При отсутствии конкретной информации агенты должны:

### Для генератора резюме:
- Использовать значение `"..."` вместо генерации фиктивной информации
- Примеры:
  - `"experience": "..."` - если нет информации об опыте работы
  - `"languages": "..."` - если нет информации о языках
  - `"achievements": "..."` - если нет информации о достижениях
  - `"education": [...]` - если есть информация, но она минимальна

### Для всех агентов:
- Не придумывать информацию, которой нет в исходных данных
- Не экстраполировать данные без явного указания на это
- Чётко различать подтверждённые и предполагаемые данные
- Использовать "..." как заполнитель для отсутствующих данных

## Принципы работы агентов

### Generator Agent
- Генерирует резюме строго по выбранной JSON-схеме
- Адаптирует подачу информации под требования работодателя
- Не изменяет фактические данные пользователя
- Использует "..." для отсутствующих данных
- Сохраняет 100% фактической точности

### Checker Agent
- Проверяет полноту и качество исходных данных
- Учитывает, что генератор будет использовать "..." для отсутствующих данных
- Фокусируется на критических ошибках и несоответствиях
- Не требует от пользователя вымышленную информацию

### Search Agent
- Собирает информацию о требованиях работодателей
- Не искажает факты, только анализирует и предоставляет рекомендации
- Учитывает, что генератор будет использовать "..." для отсутствующих данных
- Предоставляет данные в машинно-читаемом формате

### Template Selector Agent
- Выбирает формат резюме, соответствующий требованиям целевой страны/компании
- Учитывает, что генератор будет использовать "..." для отсутствующих данных
- Обеспечивает совместимость данных профиля с выбранным форматом

## Валидация данных

Система валидации проверяет:
- Соответствие JSON-схеме выбранного шаблона
- Наличие обязательных полей
- Типы данных
- Возможные галлюцинации (сравнение навыков из резюме с навыками из профиля и поискового контекста)

## Рекомендации по разработке

При разработке новых агентов или модификации существующих:
1. Всегда используйте JSON-схемы для структурированного вывода
2. Обрабатывайте отсутствующие данные с помощью "..."
3. Не генерируйте фиктивную информацию
4. Поддерживайте 100% точность фактических данных
5. Обеспечивайте совместимость с другими агентами системы
