# Генератор резюме с ИИ-агентами

Система генерации персонализированных резюме с использованием мультиагентного подхода. Система анализирует профиль пользователя, изучает требования работодателей и создает оптимизированные резюме под конкретные вакансии.

## Особенности

- **Мультиагентная архитектура**: Использует несколько специализированных агентов для анализа, поиска, генерации и проверки
- **Международные форматы**: Поддержка различных международных форматов резюме (Europass, ATS-оптимизированный, хронологический, функциональный, комбинированный, US, UK, German, French, Chinese, Japanese)
- **Адаптация под работодателя**: Резюме адаптируется под требования конкретных компаний
- **Поиск информации**: Автоматический поиск требований и предпочтений работодателей
- **Валидация данных**: Проверка качества и полноты профиля пользователя
- **Структурированный вывод**: Генерация валидного JSON-объекта по заранее определенной схеме
- **Повторные попытки**: При неудачной валидации система повторяет генерацию с корректировками

## Архитектура

Система состоит из следующих компонентов:

- `MainAgent` - Планирование и анализ профиля пользователя
- `SearchAgent` - Поиск требований работодателей
- `TemplateSelectorAgent` - Выбор подходящего международного формата резюме
- `GeneratorAgent` - Генерация структурированного резюме
- `ValidationAgent` - Валидация сгенерированного резюме
- `Graph` - Оркестрация взаимодействия агентов

## Использование

```python
from core.agents.graph import build_resume_graph

graph = build_resume_graph()

result = graph.invoke({
    "user_profile": {
        "full_name": "Иванов Иван Иванович",
        "gender": "мужской",
        "age": 30,
        # ... остальные данные профиля
    },
    "target": {
        "company": "Название компании",
        "role": "Желаемая должность"
    },
    "request_controls": {
        "target_country": "russian",  # или "us", "uk", "german", "europass" и т.д.
        "target_format": "russian"    # или "ats_optimized", "chronological", "functional" и т.д.
    }
})
```

## Форматы резюме

Система поддерживает следующие международные форматы:

- **Russian**: Российский формат резюме
- **Europass**: Европейский стандарт CV
- **ATS-optimized**: Резюме, оптимизированное для систем отслеживания кандидатов
- **Chronological**: Хронологическое резюме
- **Functional**: Функциональное резюме
- **Combination**: Комбинированное резюме
- **US**: Американский формат резюме
- **UK**: Британский формат CV
- **German**: Немецкий формат Lebenslauf
- **French**: Французский формат резюме
- **Chinese**: Китайский формат резюме
- **Japanese**: Японский формат Rirekisho

## Валидация

Система включает встроенные механизмы валидации:
- Проверка полноты и корректности профиля пользователя
- Валидация сгенерированного резюме по JSON-схеме выбранного формата
- Проверка соответствия навыков и опыта профилю пользователя
